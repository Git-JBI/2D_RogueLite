# 2D_RogueLite 기술문서

## 1. 프로젝트 개요

Unity 기반 2D 생존형 로그라이트 게임이다. 로비에서 영웅 선택, 장비 관리, 합성, 영구 능력치 강화를 수행하고 전투 씬에서 조이스틱 이동과 자동 공격으로 적을 처치한다. 경험치로 레벨을 올리며 무기·패시브를 선택하고, 제한 시간 이후 등장하는 보스를 처치하면 스테이지를 클리어한다.

전체 구조는 다음 세 축으로 구성된다.

- **영구 진행:** `GameData`와 도메인 모델이 재화, 장비, 영웅 선택, 업적, 에너지, 설정을 관리한다.
- **전투 세션:** `GameSceneModel`과 `InGameHeroModel`이 시간, 처치 수, 세션 골드, 체력, 경험치와 전투 능력치를 관리한다.
- **콘텐츠 정의:** `ScriptableObject`가 영웅·적·무기·스테이지·장비·강화 비용 등의 설정을 제공한다.

## 3. 시스템 구조와 동작

`GameManager`는 전역 서비스와 씬 간 수명을 관리하고, `GameModel`과 도메인 모델은 `GameData`를 통해 영웅·재화·장비·영구 강화·업적·에너지·설정을 관리한다. 영구 데이터는 `JsonUtility`로 직렬화하여 에디터에서는 `Assets/gameData.json`, 플레이어에서는 `Application.persistentDataPath/gameData.json`에 저장하며, 각 기능의 변경 경로에서 명시적으로 저장한다. 로비는 상점·캐릭터·스테이지·강화 메뉴로 구성되며 영웅 선택, 장비 장착·강화·합성, 장비 뽑기, 재화 교환, 업적 보상과 에너지 충전을 처리한다. 장비는 공통 설정인 `SO_EquipmentItemData`와 보유 개체인 `EquipmentItemData`로 구분하고, 영웅·장비·무기·적·스테이지의 수치와 규칙은 ScriptableObject 에셋으로 정의한다. 전투에서는 `GameSceneManager`가 선택 스테이지를 불러와 플레이어·적 생성·UI를 연결하고, `GameSceneModel`과 `InGameHeroModel`이 진행 시간·처치 수·세션 골드·체력·경험치·능력치를 관리한다. 플레이어는 조이스틱으로 이동하고 자동 공격으로 적을 처치하며, 경험치 획득에 따른 레벨업에서 무기·패시브를 선택하고 조건을 충족하면 무기를 각성시킨다. 적은 `IState` 기반 상태 머신으로 이동·공격·피격·사망을 처리하며, 시간에 따른 추가 웨이브와 제한 시간 이후의 보스 전투를 거쳐 클리어·실패 결과를 표시한다. 일시정지와 성장 선택, 전투 종료는 `Time.timeScale`로 제어하고, `ResourceManager`는 Resources 경로의 에셋을 캐시하며 `PoolManager`는 적·탄환·아이템·UI 객체를 재사용한다. 현재 장비 보너스의 전투 반영, 방어력에 따른 피해 감소, 뽑기 비용 차감, 에메랄드 결제 검증과 풀 전체 반환은 추가 구현이 필요하며, 스테이지 입장 에너지 소비량은 0으로 설정되어 있다.
